# MoeLoaderP 项目结构说明

本文描述仓库目录与模块职责，便于快速定位代码。产品功能与站点列表见根目录 [README.md](../README.md)。

---

## 1. 解决方案概览

| 工程 | 类型 | 说明 |
|------|------|------|
| **MoeLoaderP.Wpf** | WPF 桌面应用（`WinExe`） | 用户界面、窗口与控件；引用 Core。输出程序集名为 `MoeLoaderP`。 |
| **MoeLoaderP.Core** | 类库（`net9.0`） | 站点协议、搜索会话、下载逻辑、设置模型等，与 UI 解耦。 |

解决方案文件：`MoeLoaderP.sln`。历史上曾包含未入库的 `MoeLoaderP.Helper`，现已移除；相关能力已合并在本仓库的 Wpf/Core 中。

---

## 2. 启动与数据目录

- **入口**：`MoeLoaderP.Wpf/App.xaml` → `App.xaml.cs` 中 `OnStartup` 加载 `Settings`，创建 `MainWindow` 并调用 `Init(settings)` 后 `Show()`。
- **主窗口**：`MainWindow.xaml` / `MainWindow.xaml.cs`，承载各功能区域与用户控件。

`App` 中的常用路径（节选）：

| 静态成员 | 含义 |
|----------|------|
| `SettingJsonFilePath` | `%AppData%\Leaful.MoeLoader\Settings.json` |
| `CustomSiteDir` | 自定义站点 JSON 目录：`...\CustomSites` |
| `MoePicFolder` | 默认图片保存目录（「图片」下的展示名文件夹） |

---

## 3. MoeLoaderP.Core（业务与站点）

**目标框架**：`net9.0`。主要依赖：Http（WebApi Client）、JSON（Newtonsoft）、HTML 解析（HtmlAgilityPack）、图像处理（Magick.NET）等。

### 3.1 根目录类型（与站点无关的公共逻辑）

| 文件 | 职责（概括） |
|------|----------------|
| `Settings.cs` | 用户设置序列化与绑定相关模型 |
| `SiteManager.cs` | 站点列表、当前选中站点、刷新与持久化协调 |
| `MoeSite.cs`（在 `Sites/`） | 站点抽象基类；具体站点继承此类 |
| `MoeDownloader.cs` | 下载队列与任务执行 |
| `MoeItem.cs` / `MoeItemHelper.cs` | 单张图片/条目数据与辅助逻辑 |
| `SearchSession.cs` / `SearchPara.cs` | 搜索会话与参数 |
| `SearchedPage.cs` / `SearchedVisualPage.cs` | 分页与展示用页面模型 |
| `NetOperator.cs` | HTTP 等网络访问封装 |
| `Ex.cs` | 日志、全局消息回调等横切能力 |

### 3.2 `Sites/` 目录

各图片站点的具体实现，命名一般为「站点名 + Site」，例如：

- Booru 系：`BooruSite` 基类及 `KonachanSite`、`DanbooruSite`、`GelbooruSite`、`PixivSite` 等
- 其它：`BilibiliSite`、`CustomSite`（JSON 自定义站点）等

新增站点时通常在此目录增加实现，并在 `SiteManager` / 站点注册逻辑中挂接（以实际代码为准）。

## 4. MoeLoaderP.Wpf（界面）

**目标框架**：`net9.0-windows10.0.17763.0`（WPF + 指定 Windows 版本）。使用 FluentWPF、WebView2（登录等）等，详见 `MoeLoaderP.Wpf.csproj`。

### 4.1 窗口（根目录）

| 文件 | 说明 |
|------|------|
| `MainWindow.*` | 主界面壳与布局 |
| `LoginWindow.*` | 站点登录（含 WebView2） |
| `PreviewWindow.*` | 预览 |
| `LogWindow.*` | 日志窗口；内含 `LogWindowHelper` |
| `MessageWindow.*` | 消息/异常展示 |
| `EggWindow.*` | 彩蛋窗口；内含 `EggWindowHelper` |

### 4.2 `ControlParts/`

主窗口内用户控件：搜索、站点列表、缩略图网格、下载面板、设置、右键菜单、分页等，例如：

- `SearchControl`、`MoeExplorerControl`、`DownloaderControl`、`SettingsControl`
- `MoeItemControl`、`MoeContextMenuControl`、`PagingButtonControl` 等

每个控件一般为成对的 `.xaml` + `.xaml.cs`。

### 4.3 `Assets/`

- `Lang/zh-CN.xaml`：中文资源字典
- `MoeStyle.xaml`、`SimpleStyles.xaml`、`MoeResource.xaml`：样式与资源
- `SiteIcon/`、`Egg/`、`banner2.png` 等：图标与素材

### 4.4 其它

| 文件/目录 | 说明 |
|-----------|------|
| `UiUtility.cs` | WPF 扩展方法、剪贴板、Fluent 窗口效果等 |
| `Converters.cs` | XAML 绑定用值转换器 |
| `Properties/` | 应用清单等 |

## 6. 构建与运行（简记）

```bash
dotnet build MoeLoaderP.sln
dotnet run --project MoeLoaderP.Wpf/MoeLoaderP.Wpf.csproj
```

需在 **Windows** 上开发运行 WPF 客户端；Core 类库可在支持 `net9.0` 的环境下单独编译。
